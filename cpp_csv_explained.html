Reading Calories.csv with C++

A beginner-friendly breakdown of every line in the program

C++ · File I/O

i What this program does

In one sentence: it opens a CSV file called Calories.csv, reads up to 170 rows with 5 columns each, splits every line on the comma character, stores everything as text, and then prints it all back out to the screen in a neat tab-separated table.

📌 CSV stands for "Comma-Separated Values" — it's a plain text file where each line is one row of data, and commas separate the columns. Think of it like a simple spreadsheet saved as plain text.

ii Big picture flow

Before diving into each line, here's the overall journey the data takes:

Step 1Open Calories.csv from disk
Step 2Read one full line of text
Step 3Split that line into 5 pieces by comma
Step 4Store the 5 pieces in the array

Step 6Print everything to the console

1 Includes — the toolboxes we bring in

Every C++ program starts by "including" libraries — pre-written code that gives us useful tools.

#include <fstream>
#include <iostream>
#include <sstream>
#include <string>
  • <fstream> Lets us open and read files from disk (short for "file stream"). This gives us std::ifstream, used to read Calories.csv.
  • <iostream> Lets us print things to the screen, using std::cout.
  • <sstream> Lets us treat a single line of text like a mini "file" we can read piece by piece — this is how we split by comma.
  • <string> Gives us the std::string type, for working with text.

2 Setup & variables

const int ROWS = 170, COLS = 5;
std::string data[ROWS][COLS], line;
std::ifstream file("../Calories.csv");
int row = 0;
  • ROWS, COLS Two fixed numbers: the CSV has 170 rows and 5 columns. Declaring them as const int means "these never change while the program runs."
  • data[ROWS][COLS] A 2D array (a grid) of text — imagine a spreadsheet with 170 rows and 5 columns, where every cell holds a piece of text.
  • line A single empty string, used as a temporary holder for one line of the file at a time.
  • file Opens the file located one folder up (../) named Calories.csv, so we can read from it.
  • row A counter starting at 0, tracking which row of the array we're currently filling in.
⚠️ Fixed-size arrays like data[170][5] only work if you know the exact size in advance. If the real CSV has more or fewer rows, this would need adjusting (see "Common pitfalls" below).

3 Opening the file (recap)

The line std::ifstream file("../Calories.csv"); does the actual work of opening the file. ifstream means "input file stream" — a channel for reading data in from a file. If the file doesn't exist or can't be found, file quietly fails, and the loop below simply won't read any lines.

4 Reading each line

while (row < ROWS && std::getline(file, line)) {
    ...
    row++;
}
  • std::getline(file, line) Reads one full line of text from the file and stores it in line. It returns false once there's nothing left to read (end of file).
  • row < ROWS A safety check: stop once we've filled all 170 rows, even if the file has more lines.
  • && (AND) Both conditions must be true to keep looping: there must be rows left and a line must be successfully read.
  • row++ After processing a line, increase the row counter by 1 to move to the next slot in the array.

5 Splitting each line by comma

std::stringstream stream(line);
for (int col = 0; col < COLS; col++) {
    std::getline(stream, data[row][col], ',');
}
  • std::stringstream stream(line) Wraps the single line of text so it can be read piece by piece, just like reading a tiny file — this is the key trick for splitting text.
  • getline(stream, data[row][col], ',') Reads from stream up until the next comma (instead of the usual "until end of line"), and stores that chunk directly into the array.
  • for (col = 0; col < COLS) Repeats this 5 times — once per column — since we know each row has exactly 5 comma-separated values.
💡 Think of getline(stream, ..., ',') as "read text until you hit a comma, then stop there." Each call picks up right where the last one left off inside the same line.

6 Printing the result

for (int i = 0; i < row; i++) {
    for (int j = 0; j < COLS; j++) {
        std::cout << data[i][j] << "\t";
    }
    std::cout << '\n';
}
  • i < row Only loops through the rows that were actually filled in — not all 170, in case the file had fewer lines.
  • std::cout << data[i][j] << "\t" Prints each cell's text, followed by a tab character, so columns line up neatly.
  • std::cout << '\n' After printing all 5 columns of a row, moves to a new line before starting the next row.

? Beginner glossary

  • std:: A "namespace" prefix meaning "this comes from the standard C++ library." It just avoids naming clashes.
  • string A piece of text, like "hello" or "14733363" — even numbers are stored as text here.
  • array data[170][5] A grid with 170 rows and 5 columns, like a mini spreadsheet living in memory.
  • loop (for / while) A block of code that repeats automatically, instead of writing the same instruction 170 times by hand.
  • stream A flowing source of data you can read piece by piece — a file stream reads from disk, a string stream reads from text already in memory.

! Common pitfalls to watch for

  • File path "../Calories.csv" means "look one folder above where the program runs." If the .exe runs from a different folder, the file won't be found.
  • Everything is text Numbers like Age or Weight are stored as std::string, not actual numbers — so no math can be done on them without converting first (e.g. with std::stoi or std::stod).
  • Fixed size If the CSV ever has more than 170 rows or a different number of columns, this code needs its ROWS/COLS constants updated, or it should switch to a resizable std::vector.
  • No error message If the file fails to open, the program doesn't tell you — it just silently prints nothing. Adding a check like if (!file) { ... } would help beginners debug this.
